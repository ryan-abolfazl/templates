# Persian HTML Templates

Premium Persian (RTL) static HTML templates for rtl-theme.com. See [CLAUDE.md](CLAUDE.md) for structure, commands and rules.

```bash
node tools/build.mjs <slug>   # build src/<slug> -> templates/<slug>
node tools/qa.mjs <slug>      # automated QA + screenshots
tools/package.sh <slug>       # release zip in dist/
```
