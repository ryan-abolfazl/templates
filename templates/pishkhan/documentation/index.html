مستندات قالب پیشخوان

پیشخوان یک قالب HTML پنل مدیریت فروشگاهی است که با تمرکز بر خوانایی داده، سرعت و تجربه کاربری فارسی طراحی شده است. همه صفحات راست‌چین، واکنش‌گرا و دارای حالت تاریک هستند و با HTML، CSS و جاوااسکریپت خالص نوشته شده‌اند تا به‌راحتی به وردپرس، لاراول، جنگو یا هر بک‌اند دیگری متصل شوند.

  • بیش از ۲۰ صفحه آماده: داشبورد، تحلیل‌ها، سفارش‌ها، محصولات، مشتریان، فاکتور، پیام‌رسان، تقویم، کانبان، پروفایل، تنظیمات، احراز هویت و…
  • نمودارهای SVG سبک و تعاملی بدون کتابخانه خارجی
  • تقویم و انتخابگر تاریخ شمسی (جلالی)
  • جدول داده با جستجو، فیلتر، مرتب‌سازی، انتخاب گروهی و صفحه‌بندی
  • جستجوی سریع (Command Palette) با کلید Ctrl+K
  • حالت تاریک طراحی‌شده (نه صرفاً معکوس) با ذخیره انتخاب کاربر
  • منوی کناری جمع‌شونده و کشوی موبایل
  • دسترس‌پذیر: پشتیبانی کامل صفحه‌کلید و صفحه‌خوان

شروع سریع

  1. فایل فشرده را از حالت فشرده خارج کنید.
  2. پوشه html شامل همه صفحات است. فایل html/index.html را در مرورگر باز کنید؛ قالب بدون نیاز به سرور و حتی آفلاین کار می‌کند.
  3. برای انتشار، محتوای پوشه html را در هاست خود (پوشه public_html) بارگذاری کنید.
  4. متن‌ها، تصاویر و رنگ‌ها را مطابق بخش‌های زیر شخصی‌سازی کنید.

قالب هیچ درخواستی به سرورهای خارجی (CDN، گوگل فونت و…) ارسال نمی‌کند؛ بنابراین در ایران سریع و بدون مشکل بارگذاری می‌شود.

رنگ‌ها و ظاهر

همه تصمیم‌های طراحی به‌صورت متغیرهای CSS در فایل assets/css/tokens.css تعریف شده‌اند. کافی است مقدار متغیر را عوض کنید تا همه صفحات به‌روز شوند. مقادیر حالت تاریک زیر انتخابگر [data-theme='dark'] قرار دارند.

اصلی--primary#4f46e5
تأکیدی--accent#f26b5b
موفق--success#16a34a
هشدار--warning#d97706
خطا--danger#e11d48
پس‌زمینه--bg#f3f5f9
متن--text#0f1729 
:root {
  --primary: #4f46e5;   /* رنگ اصلی برند */
}

حالت پیش‌فرض (روشن یا تاریک) با ویژگی data-theme روی تگ <html> تعیین می‌شود و انتخاب کاربر در مرورگر ذخیره می‌شود.

فونت‌ها

فونت‌های قالب رایگان و دارای مجوز آزاد SIL OFL هستند و استفاده تجاری از آن‌ها مجاز است:

  • وزیرمتن (Vazirmatn): فونت متغیر برای همه متن‌ها، وزن ۱۰۰ تا ۹۰۰

برای استفاده از فونت دیگر (مثلاً فونت تجاری که لایسنس آن را خریده‌اید)، فایل woff2 را در assets/fonts قرار دهید، در fonts.css یک @font-face بسازید و متغیر --font-body را در tokens.css تغییر دهید.

کامپوننت‌های جاوااسکریپت

همه تعاملات با جاوااسکریپت خالص و بدون jQuery یا Bootstrap نوشته شده‌اند و از طریق ویژگی‌های data-* فعال می‌شوند؛ کافی است ساختار HTML را کپی کنید.

کامپوننت نحوه استفاده
حالت تاریک [data-theme-toggle] روی هر دکمه‌ای، حالت روشن/تاریک را عوض می‌کند و انتخاب کاربر ذخیره می‌شود.
منو و کشوها کشوی موبایل: data-drawer-open="id" و data-drawer؛ منوی کشویی: data-dropdown؛ هدر چسبان: data-sticky-header.
تب‌ها ساختار استاندارد role="tablist/tab/tabpanel" داخل [data-tabs] با پشتیبانی کامل صفحه‌کلید.
آکاردئون بر پایه <details>؛ با data-accordion="single" فقط یک مورد باز می‌ماند.
مودال عنصر <dialog> با data-modal-open="id" باز و با data-modal-close بسته می‌شود.
اعلان UI.toast("پیام", "success") یا ویژگی data-toast="پیام" روی دکمه.
شمارنده data-count-to="1200" عدد را با ارقام فارسی می‌شمارد.
نمودار data-chart='{"type":"area","labels":[...],"series":[...]}'؛ انواع: area, line, bar, donut, sparkline. بدون کتابخانه خارجی.
تقویم شمسی ورودی با data-datepicker انتخابگر تاریخ جلالی می‌گیرد؛ تاریخ میلادی معادل در data-gregorian ذخیره می‌شود. API: UI.jalali.
جدول داده data-table با جستجو (data-table-search)، فیلتر، مرتب‌سازی (data-sort)، انتخاب گروهی و صفحه‌بندی.
فیلتر شبکه data-filter با دکمه‌های data-filter-btn و آیتم‌های data-filter-item data-tags.
اعتبارسنجی فرم form[data-validate] پیام‌های خطای فارسی نشان می‌دهد؛ data-success پیام موفقیت. نمایش رمز و ورودی کد یکبارمصرف هم دارد.
فروشگاهی انتخاب تعداد (data-qty)، بازه قیمت (data-range)، شمارش معکوس (data-countdown)، افزودن به سبد (data-add-to-cart).

توابع کمکی سراسری: UI.fa(1250000) ارقام فارسی با جداکننده، UI.toman(n) قیمت، UI.jdate(date) تاریخ شمسی.

منوی کناری و جستجوی سریع

دکمه [data-sidebar-collapse] منو را جمع می‌کند و وضعیت آن ذخیره می‌شود. پنجره جستجو (#cmdk) با Ctrl+K یا ⌘K باز می‌شود؛ برای افزودن مورد جدید، یک لینک با کلاس cmdk__item و ویژگی data-cmdk-item اضافه کنید.

آیکن‌ها و تصاویر

آیکن‌ها از مجموعه آزاد Lucide هستند و به شکل اسپرایت SVG در assets/js/icons.js قرار دارند. نمونه استفاده: 

<svg class="icon"><use href="#i-heart"></use></svg>

برای افزودن آیکن جدید از نسخه سورس استفاده کنید (بخش بعد) یا کد SVG آیکن را مستقیماً از سایت lucide.dev کپی کنید.

تصاویر نمایشی قالب طرح‌های SVG اختصاصی هستند. برای جایگزینی، تصویر خود را به‌جای عناصر دارای کلاس ph یا فایل‌های پوشه assets/img قرار دهید.

توسعه با سورس (اختیاری)

صفحات از ماژول‌های جاوااسکریپت در پوشه source/src ساخته می‌شوند تا هدر، منو و فوتر فقط یک‌بار نوشته شوند. اگر می‌خواهید تغییرات گسترده بدهید: 

cd source
npm i -g prettier          # یک‌بار
node tools/build.mjs pishkhan   # خروجی در templates/pishkhan

برای ویرایش‌های ساده نیازی به این مرحله نیست؛ فایل‌های HTML پوشه html را مستقیم ویرایش کنید.
