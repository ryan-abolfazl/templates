# رستوران زعفران | قالب HTML رستوران ایرانی

قالب راست‌چین و واکنش‌گرای رستوران و سفره‌خانه ایرانی با منوی QR، رزرو میز و پوسته شبانه/روز.

- شروع: فایل `index.html` را در مرورگر باز کنید.
- راهنمای کامل: `documentation/index.html`
- رنگ‌ها: `assets/css/tokens.css`

فونت‌ها: وزیرمتن، لاله‌زار و نوتو نستعلیق (SIL OFL) · آیکن‌ها: Lucide (ISC) · بدون وابستگی خارجی.
