# ویترین | قالب HTML فروشگاه پوشاک

قالب راست‌چین و واکنش‌گرای فروشگاه لباس و مد با طراحی ادیتوریال و حالت تاریک.

- شروع: فایل `index.html` را در مرورگر باز کنید.
- راهنمای کامل: `documentation/index.html`
- رنگ‌ها: `assets/css/tokens.css`

فونت‌ها: وزیرمتن و نوتو کوفی عربی (SIL OFL) · آیکن‌ها: Lucide (ISC) · بدون وابستگی خارجی.
